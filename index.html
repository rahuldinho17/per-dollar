Listings and price changes on the tape, most recent first.

    Methodology. Cost per job = (input tokens × input price) + (output tokens × answer-length factor × output price). Length factors estimate how long each model's answers run for the same prompt — different tokenizers and response styles mean 1,000 tokens is not the same amount of answer everywhere; the live product measures these per task. Prices are standard-tier, first-party API list rates verified 7 July 2026; batch (~50% off) and cached-input (~90% off) rates are excluded here. Task definitions are usage-weighted from published studies (Anthropic Economic Index, OpenRouter State of AI, OpenAI usage report); each task states its assumptions above the ledger, and token footprints are estimates until the benchmark suite replaces them with measured medians. Capability is not modeled: a cheap model that fails the job costs more than a dear one that succeeds. For custom tasks: 1 token ≈ ¾ of an English word; 100 lines of code ≈ 900 tokens.
