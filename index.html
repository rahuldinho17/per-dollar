Methodology. Cost per job = (input tokens × input price) + (baseline output tokens × verbosity factor × output price). Verbosity factors are illustrative estimates of how long each model's answers run for the same prompt — the real product measures these empirically per task, because different tokenizers and response styles mean 1,000 tokens is not the same amount of answer everywhere. List prices are standard-tier, first-party API rates as of July 2026; batch discounts (~50%) and cached-input rates (~10% of input price) are excluded here. The task list is usage-weighted, drawn from published studies (Anthropic Economic Index, OpenRouter State of AI, OpenAI usage report); token footprints per task are still estimates pending an empirical benchmark suite. Capability is not modeled: a cheap model that fails the job costs more than a dear one that succeeds.
