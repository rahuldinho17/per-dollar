What this is. The router answers one question: given a task and your constraints, which model should run it? It is the same engine an agent calls through the decision API or the MCP server, so what you see here is exactly what a coding agent would receive. Prices come from the daily-verified price sheet, with human verification outranking automated checks. Capability is the Artificial Analysis Intelligence Index where published; models without a score are included only when a capability floor is not set, and are never given an invented number. Nothing is stored — this page calls a stateless endpoint and keeps no record of your query.
